# Employee Payroll System

## Description
Employee Payroll System is a C# Console Application developed using .NET Framework to demonstrate Object-Oriented Programming concepts such as Inheritance, Interface, and Polymorphism.

## Features
- Permanent Employee Payroll
- Contract Employee Payroll
- Automatic Salary Calculation
- Percentage-based DA, HRA, MA and PF
- Net Salary Calculation

## Technologies Used
- C#
- .NET Framework
- Visual Studio

## OOP Concepts Used
- Class
- Object
- Inheritance
- Interface
- Polymorphism

## Project Structure
- Employee.cs
- PermanentEmployee.cs
- ContractEmployee.cs
- IPayable.cs
- Program.cs
